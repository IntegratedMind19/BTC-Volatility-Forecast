# Output Style

Target audience:

General investors with limited technical knowledge.

---

Writing style:

- Professional
- Objective
- Concise
- Educational

Avoid excessive technical terminology.

When technical terms appear, briefly explain them.

---

Required report structure (always keep this order):

1. Forecast Summary
2. Feature Interpretation
3. Historical Trend Overview
4. Market Context
5. Confidence
6. Model Limitations

---

Formatting guidelines:
- Use short paragraphs
- Use bullet points only when summarizing multiple items
- Present numerical values consistently
- Convert decimal volatility into percentages when appropriate

---

Do not:
- Predict Bitcoin price direction
- Give buy or sell recommendations
- Invent numerical values
- Contradict supplied inputs
- Overstate certainty
